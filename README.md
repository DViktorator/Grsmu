# Расписание ГрГМУ (неофициальный клиент)

Неофициальное Android-приложение для просмотра расписания ГрГМУ (rsp-med.grsu.by).
Не связано с университетом; данные — публичное расписание.

## Стек
Kotlin · Jetpack Compose · MVVM · Jsoup · Room · Glance · WorkManager

## Сборка
Сборка идёт через GitHub Actions (`.github/workflows/build.yml`):
APK-артефакты (debug + release) прикладываются к каждому запуску.
